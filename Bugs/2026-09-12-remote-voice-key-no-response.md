# 遥控器语音键未触发 F9

## 复现

- 环境：Manjaro、X11/i3、小米蓝牙语音遥控器。
- 笔记本直接按住 F9 可以进入本地语音输入，右 Ctrl 在线语音输入正常。
- 遥控器语音键按下后无语音输入响应。

## 日志与根因

现场日志记录遥控器语音键为 `keycode=71`，旧实现只识别固定的 `69`，因此 71 被记录为未知键并透传，没有进入 F9 分支。

## 修复

第一阶段启动时读取遥控器自身的 XInput keymap，按 F 键/标准语音 keysym 语义建立候选键，不再依赖固定的 69/71。最终修复改为扫描该名称对应的 Linux evdev 节点，按 F 键/标准语音键语义识别并使用 `EVIOCGRAB` 独占读取；语音键按下和释放分别注入 F9。语音键不使用双击窗口、长按阈值或额外等待；F9 本地模型、右 Ctrl 阿里云模型及其他按键配置保持不变。

同一 evdev 独占还阻止遥控器的 `KEY_POWER` 被 `systemd-logind` 作为系统电源键处理；笔记本自身 ACPI 电源设备不匹配该规则。

该修复只复用本机已有 F9 输入路径，不恢复或替换遥控器麦克风的 ATVVoice 音频链路。

## 验证边界

- 自动化：键码识别回归测试、C 编译和现有 UI 测试。
- 本机：按键服务重启并检查 `keymap_ready` 日志。
- 待用户实测：遥控器语音键按住说话、松开结束，并确认最终文字输出；真实遥控器与输入法链路仍需现场验收。
